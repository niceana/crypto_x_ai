## 保持不变的规则

三轮调用大模型时继续由 NetworkWorker 调用 render_payload；第一轮输入原帖正文，第二轮输入当前记录与候选，第三轮输入当前记录与组内历史。请求模块原来将任务统称为“单帖”的注释改为“任务输入文本”，模板变量仍为 task.text，不修改配置。

输入准备、历史推进、数据客户端调用和网络请求继续发生在原线程、原时机；第二轮同币按时间推进，第一轮和第三轮继续共用分段执行。第二轮 Embedding 请求仍由轮次内实现负责。

表字段、日期原值与范围、候选排序、提示词、模板单次替换、三轮校验范围、状态、摘要、重试预算、保存确认、停止和恢复规则均保持不变。当前已实现的表内 embedding 列、向量 JSON 标识、阈值及 Top 10 筛选完整保留，本次不恢复历史 SQLite 方案。
